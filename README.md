# Native vs React Native Performance Demo

This Python script simulates the performance differences between native and React Native development. It demonstrates how computationally intensive tasks can affect UI responsiveness, highlighting native's advantage in handling parallel operations.

## Language

`python`

## How to Run

Run this script using Python: `python performance_demo.py`
